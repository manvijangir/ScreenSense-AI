# ScreenSense AI

An AI-powered Screen-Time Insight Dashboard built for our college hackathon.

## 🎯 Problem Statement

People spend a significant amount of time on their phones, but raw screen-time data can be difficult to understand.

Users need a simple way to visualize their digital habits, identify their most-used apps, understand their usage patterns, and receive actionable suggestions.

## 💡 Our Solution

ScreenSense AI is a web-based dashboard that analyzes an exported screen-time CSV file and converts raw usage data into meaningful insights.

It helps users understand their screen-time habits through statistics, charts, and personalized productivity suggestions.

## ✨ Key Features

- Screen-time CSV upload
- Total screen-time analysis
- Most-used app identification
- Daily usage visualization
- Weekly usage trends
- Productivity score
- AI-based productivity insights
- Personalized recommendations

## 🔄 How It Works

1. User uploads a screen-time CSV file.
2. The application reads and processes the CSV data.
3. Screen-time and app-usage patterns are analyzed.
4. The results are displayed using statistics and charts.
5. The application generates actionable productivity suggestions.

## 🚀 How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Upload the screen-time CSV file.
5. Explore the dashboard and insights.

## 📄 CSV Format

The CSV file should contain these columns:

Date,App,Minutes

Example:

10 Sep,Instagram,120
10 Sep,YouTube,90
10 Sep,WhatsApp,45
